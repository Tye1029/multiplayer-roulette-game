# Safe Cracker

This folder contains the client-side assets for the multiplayer Safe Cracker game.

Planned structure:

- `safe-cracker.js` — game presentation and controls
- `safe-cracker.css` — game-specific styling
- `images/` — Safe Cracker artwork
- `audio/` — Safe Cracker sound effects

Development must remain on the `safe-cracker-development` branch until the game is approved.
