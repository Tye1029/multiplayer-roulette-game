# Safe Cracker sample mix v11

These optimized mono MP3 payloads were made from user-supplied recordings and are stored as Base64 text so the static build can load them without changing repository binary handling.

- `submit-latch.b64` — derived from `freesound_community-vault-88618.mp3`; short number-submission latch.
- `tumbler-lock.b64` — derived from `freesound_community-locking-door-6854.mp3`; successful tumbler lock.
- `safe-unlock.b64` — derived from `dragon-studio-heavy-door-unlocking-515258.mp3`; first bolt/unlock layer.
- `safe-bolt-mechanism.b64` — derived from `freesound_community-bank-vault-100469.mp3`; internal vault mechanism layer.
- `safe-door-open.b64` — derived from `freesound_community-vault-2-100077.mp3`; safe-door opening body and resonance.
- `safe-door-lockdown.b64` — derived from `audiopapkin-closing-large-metal-door-003-369393.mp3`; loss/tie vault lockdown.

Processing: trimmed to useful transients, mono 44.1 kHz, 40–64 kbps MP3, high/low-pass cleanup, loudness normalization, and short edge fades. Runtime gain staging and compression provide the final mix.

The recordings were supplied by the project owner. Verify and retain the original source licenses/attribution requirements before public or commercial release.
