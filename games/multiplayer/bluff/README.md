# Bluff or Bust

Entry: `/games/multiplayer/bluff/`. Release: `BLUFF_OR_BUST_V2` (existing V1 saved states remain compatible).

Ten independently randomized crowns/coins/skulls per player. Players simultaneously commit any nonempty subset of their hand within 30 seconds. Missing this server deadline forfeits; both missing is a draw. Only when both commit are play counts visible. Players secretly choose Believe or Call Bluff in 20 seconds (missing choice defaults to Believe). All cards are then revealed.

Believed plays are discarded. A challenged play containing any fake returns to its owner. An entirely genuine challenged play goes to the accuser. Both original plays are removed before transfers, and empty hands are checked only after both resolutions. Both empty is a draw. Reveals last 6 seconds plus 260ms per card in the larger play before the next round or result. The target symbol is independently randomized each round.

Online tables and the network bot reuse the existing verified RPS session authentication; no wallet/stake operations occur. Friends share a private table link/code and both press Ready before dealing. The creator can add the Velvet Fox bot to an empty waiting seat; this server action is serialized with human joins and never replaces an opponent. Adding a bot does not start the clock until the creator presses Ready. PostgreSQL row locks serialize concurrent choices; match/round identity rejects stale actions. Repeat submissions cannot change locked choices. Reads also advance expired clocks; timeouts are effective at the deadline even if materialized on the next request. The bot uses only its own hand and the public committed-card count. Both players must consent to a rematch; the bot automatically consents.

The page uses the shared site settings/account header and a centered game title. Test with bot is available from the lobby. Without a connected account, practice uses the same rules and an in-browser bot. Session storage resumes it across reloads, with elapsed deadlines still enforced. Local practice is not an authoritative or wagered match. Online state is recovered from the server after reload. A 15-minute unused invitation expires. Online create retries use an idempotent request ID; owners are limited to five recent unfinished tables.

Owned sources: `shared/games/bluff-model.js`, `assets/bluff/`, `netlify/functions/bluff/`, and `netlify/functions/bluff-action.js`. Artwork is original scalable SVG, loaded only on the game page except its small home tile cover. No historical game assets were superseded; existing art is retained because other games still reference it.

Validation: `node scripts/validate-bluff.mjs`, `node scripts/bluff-http.test.mjs`, and `npm run build`. The HTTP test uses two identities and an in-memory store through the real API handler; it does not claim to exercise deployed PostgreSQL. The Bluff workflow runs both plus protected and Summit checks. Browser QA should cover desktop/mobile, selections, lock/reveal, large transfers, reload, timeout, two independent players, and rematches.
