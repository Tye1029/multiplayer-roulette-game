# Torn Bookie ChatGPT Score Checker

This folder is isolated on the `torn-bookie-score-checker` branch and does not change the roulette game's `main` branch.

## Deploy on Render

Create a new Web Service from this GitHub repository and use:

- Branch: `torn-bookie-score-checker`
- Root Directory: `torn-bookie-score-checker`
- Runtime: Docker
- Health Check Path: `/health`

After deployment, the ChatGPT MCP Server URL is:

`https://YOUR-RENDER-SERVICE.onrender.com/mcp`

No API key is required by this v0.1 score checker.
