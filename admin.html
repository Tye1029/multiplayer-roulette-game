Adjust User Balance

Manual changes update the user’s server-side balance and are saved in the audit log. Users will see the updated balance the next time they save/check their key or check sent Tickets to convert deposits into Tickets.

Multiplayer Testing

Temporary test tool: cancel/remove every current multiplayer game and refund escrowed Tickets from incomplete games back to real players.

Live Odds Control

Per-game controls replace the old single global odds workflow. Scratch Tickets use the scratch profile, Multiplayer uses a house cut, and Street Runner uses a rising-risk multiplier curve. This is a long-run edge, not guaranteed profit every session.

Street Runner: higher base chance is easier at the start. Chance drops every safe turn and as the multiplier rises. Multiplier increase grows every safe turn.

Advanced Scratch User Overrides

Probabilities can total any positive number; the server normalizes them. RTP below 100% gives the house a statistical advantage over many tickets.
